# OneByte-FE

## 🔎주요기능

### 🏫 학원 등록 및 합류 기능

**사용자는 해당 서비스를 사용하기 위해 본인의 학원을 선택해요 !**

- 학원을 관리하기 위해 학원을 등록
- 기존 학원에 합류할 경우, 관리자가 초대한 회원만이 인증 코드를 통해 가입

### 🎓학생 관리 기능

**학생들의 전체적인 출결을 관리해요 !**

- 학생들의 출결을 ○ (출석) / X (결석) /△ (지각) 관리
- 학생들의 월별 출결을 통계 그래프 및 엑셀 파일 제공
- 학부모에게 SMS 메시지 전송

### 📊 성적 관리 기능

**학원에서 매번 치르는 시험을 관리해요 !**

- 시험에 대한 정보를 조회
- 해당 시험을 치른 학생에 대한 개인 리포트 제공

### 📅 일정 관리 기능

**바쁜 학원 일정을 캘린더로 관리해요 !**

- 개인 일정 및 학원 일정별로 나눠 일정 관리
- 카테고리에 따른 일정 세분화

### 🗂️ 드라이브 기능

**학원 선생님들은 필요한 자료를 보다 쉽게 관리해요 !**

- 개인 드라이브와 공용 드라이브(학원 드라이브)에 필요한 자료를 업로드
- 업로드한 자료를 조회 및 다운로드
- 삭제한 파일을 휴지통에서 관리하여 영구 삭제 및 복원
